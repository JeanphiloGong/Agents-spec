# 发布 AGENTS.md Web 应用计划（PM）

## 目标与范围
- 目标：统一索引/搜索/筛选/下载所有 AGENTS.md，降低查找成本。
- 范围：Web 端（首页、列表、详情、关于），支持搜索/筛选/标签。
- 非范围：权限体系、多人协作编辑、复杂审核流（后续阶段）。

## MVP 交付清单
- AGENTS.md 文件索引与元信息抽取（路径、部门、角色、更新时间）。
- 全文搜索（标题 + 内容 + 标签）。
- 筛选：部门 / 角色 / 类型（spec/template/tutorial）。
- 标签：自动标签（基于路径或文件头）。
- 详情页：Markdown 渲染 + 下载原文件。

## 信息架构
- 首页：搜索入口 + 分类入口 + 热门标签 + 最近更新。
- 列表页：结果列表 + 筛选区 + 排序（最新/名称）。
- 详情页：正文渲染 + 元信息卡片 + 下载入口 + 相关推荐。
- 关于页：如何使用 AGENTS 规范与更新策略。

## 数据与模型（建议字段）
- id, title, path, dept, role, type, tags[], updated_at, excerpt, content
- 规则：从路径推导 dept/role/type；若有 Front Matter 则优先。

## 指标与验证
- 搜索命中率 ≥ 80%
- 访问→下载转化率 ≥ 30%
- 平均查找时长 < 20 秒

## 风险与假设
- 假设：目录结构一致，可稳定抽取元信息。
- 风险：内容差异大导致搜索噪声；需设权重与精简摘要。

## 里程碑
- M1：完成索引与列表 + 详情页。
- M2：接入搜索与筛选。
- M3：标签与相关推荐优化。

## 所需支持
- 是否允许修改前端代码（WRITE_CODE）。
- 部署方式选择：静态站 or 动态服务。
