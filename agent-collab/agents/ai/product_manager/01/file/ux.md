# AGENTS 发布站 UX 设计（适配当前场景）

## UX 目标
- 10 秒内定位目标 AGENTS 文档。
- 1 次点击完成下载或复制。
- 新用户 1 分钟内理解用途与使用方式。

## 核心流程（首选路径）
首页输入关键词 → 列表页筛选缩小 → 详情页确认 → 下载/复制

## 页面体验设计

### 首页
- 大搜索框为主（默认聚焦，支持回车搜索）。
- 入口分区：按部门/角色快速浏览。
- 辅助区：最近更新 + 热门标签。

### 列表页
- 筛选：部门、角色、类型、更新时间。
- 结果卡片：标题 + 一行摘要 + 标签 + 路径。
- 结果反馈：命中数量 + 关键词高亮。

### 详情页
- 左侧目录导航（长文档快速跳转）。
- 右侧元信息：部门/角色/路径/更新时间。
- 主 CTA：下载原文件 / 复制链接 / 复制内容。
- 相关推荐：同部门/同标签。

## 关键交互细节
- 搜索建议：输入时展示匹配标题/标签。
- 空结果态：提示调整关键词 + 推荐相关标签。
- 筛选状态可见：支持一键清空。
- 高亮命中：标题与正文摘要高亮关键词。

## 信息组织规则
- 从路径自动推导部门/角色/类型。
- 标签来源：目录 + 文件标题关键词。
- 若后续增加 Front Matter，可提升准确度。

## 新手引导
- “如何使用”入口，包含安装/落地示例。
- 详情页首屏展示用途与核心范围，便于快速判断匹配度。
