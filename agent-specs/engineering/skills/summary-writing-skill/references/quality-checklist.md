# 总结质量自检清单

## 结构与信息完整性
- [ ] 明确总结类型与时间范围。
- [ ] 至少 3 条可验证成果（数据/证据/TODO）。
- [ ] 每条成果都说明影响对象与业务意义。
- [ ] 有风险/阻塞与应对（如适用）。
- [ ] 有下一阶段责任与边界。

## 价值与战略
- [ ] 至少 1 条“闭环结果”。
- [ ] 至少 1 条“杠杆/复用/机制”。
- [ ] 至少 1 条“资产沉淀”。
- [ ] 至少 1 条“从 A 到 B 的变化”。
- [ ] 明确关键矛盾或关键问题。

## 表达规范
- [ ] 技术内容已翻译为业务指标或战略意义。
- [ ] 语气克制，避免口号与情绪化。
- [ ] 数据与结论一致，无夸大或虚构。
- [ ] 无敏感/保密信息与个人隐私。
