# Frontend UX Optimization Skill

## Master Principles

- Reduce cognitive load with clear hierarchy and progressive disclosure.
- Optimize flows around user goals, not internal system structure.
- Make system state visible with timely, meaningful feedback.
- Prevent errors and provide fast recovery paths.
- Keep interactions consistent while prioritizing the critical path.
- Design for accessibility and inclusivity from the start.

## Workflow

1. Clarify user context.
   - Primary users, goals, and top tasks.
2. Map the critical flow.
   - Identify entry, key decisions, success criteria, and drop-off points.
3. Audit friction.
   - Find ambiguity, unnecessary steps, and unclear affordances.
4. Define interaction improvements.
   - Feedback, latency handling, navigation, and error recovery.
5. Validate with heuristics.
   - Consistency, visibility, error prevention, and accessibility checks.
6. Produce actionable guidance.
   - Prioritized recommendations, rationale, and quick wins.

## Required Inputs

- Product type and target users
- Primary user goals and top tasks
- Key screens or flows (links or screenshots if available)
- Known pain points or metrics (bounce, conversion, drop-off)
- Constraints (brand, tech, timelines)

## Output Format

```
## UX Diagnosis
## Priority Improvements
## Flow Changes
## Interaction & Feedback
## Accessibility Notes
## Quick Wins
## Risks & Assumptions
```

## Guardrails

- Do not invent user research results or metrics; mark as assumptions.
- Do not propose changes that conflict with stated constraints.
- Keep recommendations focused on user impact and measurability.
