# Delivery Goal Doc Template

Use this reference when the document's primary intent is a detailed local
delivery or implementation plan.

## Recommended Sections

- Summary
- Scope
- Proposed Change
- File Change Plan
- Execution Order
- Verification
- Risks
- Related Docs

## Rule

Keep delivery-goal docs local to the owning node when they contain implementation
detail that would be lost inside a broader parent document.
