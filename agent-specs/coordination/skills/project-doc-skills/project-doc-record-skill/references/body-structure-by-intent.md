# Body Structure By Intent

Use this reference when choosing the body structure for the document.

## Purpose

Prefer:
- Purpose
- Scope
- Responsibilities
- Child Nodes or Related Areas
- Related Docs

## Proposal

Prefer:
- Summary
- Context
- Scope
- Proposed Change
- File Change Plan
- Verification
- Risks

## Current-State

Prefer:
- Scope or Boundary
- Responsibilities
- Data or Control Flow
- External Interfaces
- Related Docs

## Contract

Prefer:
- Scope
- Contract
- Semantics
- Compatibility Notes
- Examples

## Guide

Prefer:
- Goal
- Preconditions
- Steps
- Verification
- Troubleshooting

## Operation

Prefer:
- Trigger or Symptoms
- Preconditions
- Steps
- Verification
- Rollback
- Escalation

## Rule

Use the document's intent to choose structure. Do not reuse one generic formal
outline for every artifact.
