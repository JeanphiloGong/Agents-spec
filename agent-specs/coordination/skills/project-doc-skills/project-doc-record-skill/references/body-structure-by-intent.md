# Body Structure By Intent

Use this reference when choosing the body structure for the document.

## Purpose

Prefer:
- Purpose
- Scope
- Responsibilities
- Child Nodes or Related Areas
- Related Docs

## Repo Landing README

Prefer:
- Project Purpose
- Main Capabilities
- Repository Orientation
- Getting Started or Entry Cues
- Short Docs Pointer

## Node Entry README

Prefer:
- Purpose
- Responsibilities or Boundaries
- Main Flow
- Key Areas or Child Nodes
- Related Docs

## Docs Landing README

Prefer:
- Scope
- Start Here or Reading Order
- Current Authority Routes
- Doc Categories
- Related Nodes

## Proposal

Prefer:
- Summary
- Context
- Scope
- Proposed Change
- File Change Plan
- Verification
- Risks

## Current-State

Prefer:
- Scope or Boundary
- Responsibilities
- Data or Control Flow
- External Interfaces
- Related Docs

## Contract

Prefer:
- Scope
- Contract
- Semantics
- Compatibility Notes
- Examples

## Guide

Prefer:
- Goal
- Preconditions
- Steps
- Verification
- Troubleshooting

## Operation

Prefer:
- Trigger or Symptoms
- Preconditions
- Steps
- Verification
- Rollback
- Escalation

## Rule

Use the document's intent to choose structure. Do not reuse one generic formal
outline for every artifact. For README pages that are not docs landings, keep
docs pointers brief and late.
