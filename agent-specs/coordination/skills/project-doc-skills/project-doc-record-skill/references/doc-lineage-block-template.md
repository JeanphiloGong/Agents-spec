# Doc Lineage Block Template

Use this when the relationship between documents would be hard to infer from
front matter alone.

## Template

```text
## Doc Lineage
- Proposed by:
- Decided by:
- Current state in:
- Contract defined in:
- Related guide:
- Operated with:
```

## Usage Notes

- Omit lines that truly do not apply.
- Prefer explicit labels over a raw list of links.
- Use this especially for RFC promotion, architecture pages, and ADRs.
