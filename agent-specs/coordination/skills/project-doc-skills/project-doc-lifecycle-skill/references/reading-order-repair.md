# Reading Order Repair

Use this reference when file placement is technically acceptable but readers
still do not know what to read first, next, or only if needed.

## Common Reading Problems

- no obvious start page
- overview missing between entrypoint and local detail
- proposal pages appearing before current authority pages
- sibling docs with no ordering or neighbor links
- deep local pages with no route back to the broader context

## Repairs

Common repairs include:
- add or strengthen an entry cue
- add an overview or bridge page
- add related-reading or next-step links
- demote historical pages behind current authority
- update indexes or parent summaries

## Rule

If a reasonable reader would still ask "what do I read next," the system is
not yet editorially healthy.
