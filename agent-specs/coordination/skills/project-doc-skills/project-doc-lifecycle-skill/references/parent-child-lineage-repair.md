# Parent Child Lineage Repair

Use this reference when the doc family needs clearer forward and backward
links.

## Minimum Repairs

- parent docs link to active child docs
- child docs link back to the parent summary or origin proposal
- implemented proposals link forward to current-state
- superseded docs link to replacements

## Goal

Readers should be able to move from broad context to local detail and back
again without guessing which doc is current.
