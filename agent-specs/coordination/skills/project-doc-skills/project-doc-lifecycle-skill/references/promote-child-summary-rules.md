# Promote Child Summary Rules

Use this reference when deciding how promotion changes parent and child docs.

## Parent Keeps

- short summary of what changed
- link to the child or current-state doc
- index guidance for discovery

## Child Keeps

- local current-state or proposal detail
- implementation boundaries
- verification and local risks when still relevant

## Rule

Promotion should not move all child knowledge upward. It should make the local
source of truth easier to find.
