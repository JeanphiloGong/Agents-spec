# Reading Order And Book-Slice Readiness

Use this reference when file placement is roughly acceptable but readers still
do not know what to read first, next, or only if needed.

## Common Reading Problems

- no obvious start page
- overview missing between entrypoint and local detail
- proposal pages appearing before current authority pages
- sibling docs with no ordering or neighbor links
- deep local pages with no route back to the broader context

## Common Repairs

- add or strengthen an entry cue
- add an overview or bridge page
- add related-reading or next-step links
- demote historical pages behind current authority
- update indexes or parent summaries

## Book-Slice Readiness Checks

Check whether the maintained scope has:

- a clear start page
- at least one explicit reading route
- visible canonical pages
- historical pages that point forward
- no critical missing bridge docs

## Lightweight Slice Plan

A lightweight book-slice plan usually records:

- included pages
- recommended reading order
- canonical versus historical status
- missing pages that still block a clean slice

## Default Rule

The goal is not a publishing pipeline. The goal is to keep one maintained scope
structured enough that it reads like a coherent book slice.
