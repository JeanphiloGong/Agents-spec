# Lineage Repair Rules

Use this reference when a document family needs better forward and backward
links.

## Minimum Repairs

- proposals should link forward to current-state or decision docs when they
  exist
- current-state docs should link backward to source proposal or decision docs
- superseded docs should link to their replacement
- related contract, guide, and runbook docs should be linked when they became
  part of the same lifecycle wave

## Goal

Readers should be able to move:
- from a proposal to what became real
- from a current-state page back to why it exists
- from an old doc to the current replacement
