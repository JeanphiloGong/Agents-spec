# Book Manifest And Export Readiness

Use this reference when a maintained documentation scope should be readable as
a coherent project-book slice.

## Book Readiness Checks

Check whether the scope has:
- a clear start page
- at least one explicit reading route
- visible canonical pages
- historical pages that point forward
- no critical missing bridge docs

## Export Manifest

An export manifest can stay lightweight. It usually records:
- included pages
- recommended reading order
- canonical versus historical status
- missing pages that block a clean export

## Rule

The goal is not a fancy publishing pipeline. The goal is to keep the docs
structured enough that assembling a project-book view is straightforward.
