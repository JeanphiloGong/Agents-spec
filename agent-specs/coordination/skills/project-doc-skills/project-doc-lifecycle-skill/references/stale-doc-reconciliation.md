# Stale Doc Reconciliation

Use this reference when current docs overlap, contradict each other, or lag
behind implementation.

## Questions

- Which doc is still authoritative?
- Which doc became historical but should still remain readable?
- Which doc should point to a replacement?
- Which links are missing between proposal, decision, and current-state?

## Preferred Actions

- mark old docs `superseded` when replaced
- add replacement links
- archive only when the doc is no longer needed for normal discovery
- keep historical context discoverable rather than deleting it
