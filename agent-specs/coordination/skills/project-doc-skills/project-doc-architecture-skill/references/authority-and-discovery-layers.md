# Authority And Discovery Layers

Use this reference when deciding whether a page should route readers or own the
technical truth.

## Discovery Layers

Discovery pages help readers find the next correct page.

Common discovery layers:
- repository landing page
- documentation landing page
- overview pages
- indexes

## Authority Layers

Authority pages are where the repository expects readers to rely on the
current truth for a given boundary.

Common authority layers:
- current-state pages
- stable contracts or specs
- node-local technical summaries

## Rule

Discovery pages point. Authority pages own. Do not mix the two unless the
scope is truly small enough that one page can do both clearly.
