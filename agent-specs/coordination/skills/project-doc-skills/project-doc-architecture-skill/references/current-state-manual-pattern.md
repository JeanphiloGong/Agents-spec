# Current-State Manual Pattern

Use this reference when choosing the landing page that owns the "how the
system works now" role.

## Purpose

The current-state layer should:
- explain the system's present boundaries and major flows
- help readers find deeper authoritative docs
- change when implemented behavior materially changes system understanding

## Anti-Pattern

Do not let the current-state layer copy every RFC, ADR, spec, guide, and
runbook in full. It should guide and summarize, not duplicate all authority.
