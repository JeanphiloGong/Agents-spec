# Active vs Reserved Types

Use this reference when deciding which doc types should be part of the normal
 writing flow and which should stay available but optional.

## Default Active Types

- `rfc`
- `architecture`
- `guide`
- `policy`

## Default Reserved Types

- `adr`
- `spec`
- `runbook`
- `postmortem`

## Rule

Only activate a reserved type when the repository has recurring, real usage for
that role. Do not keep empty directories alive just to make the taxonomy look
complete.
