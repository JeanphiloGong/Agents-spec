# Index and Navigation Rules

Use this reference when deciding which entry pages and indexes the repository
should maintain.

## Root Index

The root docs entry should help readers find:
- overview
- current state
- active changes
- decisions
- contracts
- development
- operations
- governance

## Section Indexes

Maintain section indexes when:
- a category has multiple documents
- readers need a stable place to discover current pages
- a section acts as a curated current-state or lifecycle landing page

## Module Indexes

Create module indexes only when the module has enough surface area that local
docs need their own navigation layer.
